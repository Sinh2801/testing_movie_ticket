================================================================================
              CINEPRIME FRONTEND DESIGN & UI SYSTEM DOCUMENTATION
================================================================================

1. NGUYÊN TẮC THIẾT KẾ (DESIGN PRINCIPLES)
--------------------------------------------------------------------------------
- Phong cách: Dark Mode Cinematic (Hiện đại, sang trọng, tương phản cao như Netflix/Cinema UI).
- Cảm xúc thị giác: WOW factor, hiệu ứng kính mờ (Glassmorphism), bóng đổ mềm (Soft Shadows), 
  bo góc tròn lớn (Rounded 2XL/3XL) mang lại cảm giác vô cùng mượt mà.

2. BẢNG MÀU CHUẨN (COLOR PALETTE)
--------------------------------------------------------------------------------
- Nền chính (Background): 
  + Main App Background : #020617 (slate-950)
  + Card Background     : #0f172a (slate-900 / slate-900/90 backdrop-blur-xl)
  + Border Color        : #1e293b (slate-800 / slate-800/80)

- Tông màu chủ đạo (Primary & Brand Accent):
  + Primary Red/Rose    : #e11d48 (rose-600) -> Gradient: from-rose-600 to-pink-600
  + Rose Glow           : shadow-rose-600/30, shadow-rose-600/50
  + MoMo Brand Pink     : #ae2070 / #d82d8b (pink-600)

- Trạng thái & Highlight (Status & Highlights):
  + Success / Available : #34d399 (emerald-400) / bg-emerald-500/10
  + Warning / Price     : #fbbf24 (amber-400) / font-black text-amber-400
  + Occupied Seat       : #475569 (slate-600) / cursor-not-allowed
  + Text Colors         : #ffffff (Title), #cbd5e1 (Body text-slate-300), #94a3b8 (Muted text-slate-400)

3. TYPOGRAPHY & FONT SIZES
--------------------------------------------------------------------------------
- Font Family: Inter, System Sans-serif (Clean, readable, modern)
- Typography Hierarchy:
  + Heading XL (Trang chính)  : text-3xl font-black (30px)
  + Heading L (Card Title)   : text-xl font-bold (20px)
  + Heading M (Sub-header)   : text-base font-extrabold (16px)
  + Body Normal              : text-sm (14px)
  + Caption & Badge          : text-xs / text-[11px] font-bold uppercase tracking-wider

5. QUY TRÌNH KHI BỔ SUNG GIAO DIỆN MỚI
--------------------------------------------------------------------------------
1. Giữ nguyên cấu trúc Header và Footer dùng chung bằng hàm `renderHeader()` và `renderFooter()`.
2. Kiểm tra trạng thái đăng nhập qua `authService.isLoggedIn()` và phân quyền Admin/User.
3. Ưu tiên các animation tự nhiên (transition-all duration-200/300) và luôn cung cấp trạng thái Loading/Empty state rõ ràng cho người dùng.
