1. TỔNG QUAN HỆ THỐNG (SYSTEM OVERVIEW)
--------------------------------------------------------------------------------
Hệ thống Đặt Vé Xem Phim CinePrime với backend Spring Boot RESTful API và 
frontend Vanilla Javascript / Tailwind CSS cao cấp. Hỗ trợ hệ quản trị admin 
và người dùng đặt vé trực tuyến kèm mô phỏng thanh toán MoMo Gateway và gửi email 
xác nhận qua Gmail SMTP.

2. DANH SÁCH API BACKEND (ENDPOINTS & DTOs)
--------------------------------------------------------------------------------
[AUTHENTICATION]
- POST /api/auth/register      : Đăng ký tài khoản (RegisterRequest -> AuthResponse + JWT)
- POST /api/auth/login         : Đăng nhập tài khoản (LoginRequest -> AuthResponse + JWT)

[GENRES MANAGEMENT]
- GET /api/genres/all          : Lấy danh sách thể loại phim
- GET /api/genres/gerne/{id}  : Lấy 1 thể loại phim theo id
- POST /api/genres/add         : Thêm mới thể loại (Admin)
- PUT /api/genres/edit/{id}    : Sửa thể loại (Admin)

[CINEMAS MANAGEMENT]
- GET /api/cinemas             : Lấy danh sách rạp chiếu phim
- GET /api/cinemas/cinema/{id} : Lấy phim theo id
- POST /api/cinemas/add        : Thêm cụm rạp mới (Admin)
- PUT /api/cinemas/edit/{id}   : Sửa thông tin rạp chiếu (Admin)

[ROOMS MANAGEMENT]
- GET /api/rooms/cinema/{id}   : Lấy danh sách phòng chiếu theo ID rạp
- POST /api/rooms/add          : Thêm phòng chiếu mới + tự sinh sơ đồ ghế (Admin)
- PUT /api/rooms/edit/{id}     : Sửa thông tin phòng chiếu (Admin)

[MOVIES MANAGEMENT]
- GET /api/movies/filter       : Filter phim thành page chứa tên
- GET /api/movies/now-showing  : Filter phim thành page đang chiếu
- GET /api/movies/coming-soon  : Filter phim thành page sắp chiếu
- GET /api/movies/{id}         : Lấy thông tin chi tiết phim
- POST /api/movies/add         : Thêm phim mới (Admin)
- PUT /api/movies/edit/{id}    : Cập nhật thông tin phim (Admin)

[SHOWTIMES MANAGEMENT]
- POST /api/showtimes/add      : Tạo suất chiếu mới (Admin) -> Tự động sinh danh sách ShowTimeSeat
- GET /api/showtimes/filter    : Lọc suất chiếu theo cinemaId, date, movieName
- GET /api/showtimes/movie/{id}: Lấy danh sách suất chiếu của 1 bộ phim
- GET /api/showtimes/{id}      : Lấy chi tiết suất chiếu
- GET /api/showtimes/{id}/seats: Lấy sơ đồ ghế và trạng thái (AVAILABLE, BOOKED) của suất chiếu

[TICKET BOOKING & CANCELLATION]
- POST /api/tickets/book       : Đặt vé mới (CreateTicketRequest -> TicketResponse status PENDING)
- POST /api/tickets/{id}/cancel: Hủy vé đã đặt (Yêu cầu ít nhất 2 tiếng trước giờ chiếu). Tự động đổi trạng thái vé thành CANCELLED, hoàn ghế ShowTimeSeat về AVAILABLE, gửi email xác nhận.
- GET /api/tickets/history     : Lấy danh sách vé đã đặt của user đang đăng nhập
- GET /api/tickets/{id}        : Lấy thông tin vé theo ID
- GET /api/tickets/uid/{uid}   : Lấy thông tin vé theo mã UID duy nhất

[PAYMENT & EMAIL]
- POST /api/payments/momo/create  : Tạo yêu cầu thanh toán MoMo Sandbox
- POST /api/payments/momo/callback: Nhận callback từ MoMo -> Chuyển vé sang CONFIRMED, ghế sang BOOKED, tự động gửi Email xác nhận qua Gmail SMTP (với cơ chế Fallback Logger).

3. CÁC TÍNH NĂNG FRONTEND ĐÃ HOÀN THIỆN
--------------------------------------------------------------------------------
- Admin Dashboard:
  + Quản lý Phim, Thể loại, Rạp chiếu, Phòng chiếu.
  + Quản lý Suất chiếu: Tạo mới suất chiếu, Bộ lọc theo rạp, lọc theo ngày chiếu, tìm kiếm theo tên phim.
- User Booking Flow:
  + Trang chi tiết & chọn suất chiếu.
  + Sơ đồ chọn ghế trực quan (real-time seat status từ backend).
  + Trang xác nhận đơn hàng & phương thức thanh toán.
  + Cổng thanh toán mô phỏng MoMo Gateway (payment-success.html).
  + Trang Hồ sơ cá nhân (profile.html): 
    * Xem Lịch sử đặt vé.
    * Hủy vé xem phim (Hiển thị nút Hủy vé nếu cách giờ chiếu >= 2h, tự động làm mới danh sách và cập nhật sơ đồ ghế).
    * Đổi mật khẩu tài khoản.
